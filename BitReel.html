    This animation

    Animations in a project share the palette, key and pixel settings, so a character set looks consistent. Each keeps its own frames, trim, grid, frame rate, loop mode, paint edits and stabilization. A new animation keeps the loaded video, so idle, run and jump can come from different parts of one clip.

    Stabilize off

    Keeps the character on the spot, so a walk or run cycle plays in place the way game sprites need. It tracks the opaque pixels, so key out the background or mark a transparent swatch first. Frames move by whole pixels, and paint edits sit on top of the stabilized frames.

      Sprite frame

      px

      Trimming crops every frame to the tightest box around the opaque pixels across the whole loop. With the same size option, every animation shares one frame and their anchors (the feet) line up, so switching from idle to run doesn't make the sprite jump.
